# v8 实验资产恢复版版本说明

v8不改变论文的尺度理论、隐状态估计、尺度残差估计和月度反馈校正主线，也不改变2020年2月696 h自然月主实验与v7 Jan-wind冻结口径。

本版解决两个复现缺口：

1. **Jan-target / Jun-target**：确认早期实验确实存在并保存结果，但历史精确窗口与完整脚本未恢复。因此保留旧CSV为legacy provenance，同时建立新的、明确日期且端到端可运行的跨时段验证：统一使用Jan 1–7独立先验，目标为Jan 8–14与Jun 8–14。
2. **AC审计**：确认旧case39/case118实验体系真实存在，但当前工程无法逐项复现全部历史设置。因此旧协议与数值归档为legacy；正文改用同一RTS-GMLC 73节点网络上的自包含确定性有损AC断面，专门审计空间恒等式和网损责任暴露。

版本优先级：当前 `reference/expected_*.csv` > 论文v8 > docs > legacy provenance。旧Jan/Jun和旧case39/case118数值不再作为正文当前结果。
