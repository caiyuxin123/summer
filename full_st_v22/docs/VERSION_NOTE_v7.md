# v7 可复现定稿版版本说明

## 1. 为什么产生 v7

论文 v6 的 696 h 完整自然月主实验已经能够由当前工程端到端复现，理论、主表和主结论均稳定。

v6 的 Jan-wind 扩展表格同样来自此前真实保存的实验输出，但当时只冻结了结果文件，没有把产生该结果的全部场景构造参数和处理逻辑一并完整保存。后续重新整理工程时，仅凭结果文件无法无歧义恢复其全部隐式设置。

为使最终投稿稿件满足“论文数字—算法代码—原始数据—配置—自动核验”闭环，v7 对 Jan-wind 扩展实验进行可复现口径重置，并把场景定义写入代码与 metadata。

## 2. v7 Jan-wind 的唯一有效定义

- 历史期：2020-01-01—01-07；
- 目标期：2020-01-08—01-14；
- 区域负荷：官方 RTS-GMLC 原始值，不缩放；
- 风电：四条官方时序作为对应固定风电机组的逐时 `pmax`；
- 网络与常规机组容量：不缩放；
- 风电运行阶段直接 CO₂：0；
- 物理链：DC-OPF → 潮流 → 节点 CEF → Area 聚合；
