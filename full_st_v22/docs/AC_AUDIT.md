# v8 自包含有损 AC 空间恒等式审计

主性能实验采用RTS-GMLC DC-OPF。为独立验证理论中的网损责任暴露项，v8改用**同一RTS-GMLC 73节点静态网络**构造确定性有损AC责任断面，避免当前论文再依赖未完整恢复的旧case39/case118实验代码。

## 数据与构造

- 母线电压幅值/相角：捆绑的官方 `bus.csv`；
- 支路 R/X/B 与变比：捆绑的官方 `branch.csv`；
- 使用两端口π型AC支路模型计算端口有功；
- 每条有损支路分解为非负中点传输与端点损耗；
- 在源、荷两侧增加相同正基量，保证节点功率平衡且每个固定Area均有正负荷；
- 使用确定性异质碳标签只为激发恒等式。

该断面仅用于**恒等式与网损项数值审计**，不解释为实际调度排放场景，也不参与主性能比较。

## 当前冻结结果

- 73 buses / 120 branches / 3 Areas；
- 最大节点功率平衡残差：`1.136868e-13 MW`；
- 总有功损耗：`134.460721 MW`；
- 空间恒等式最大闭合误差：`1.660965e-10`；
- 边界—网损分解最大闭合误差：`1.660396e-10`；
- 边界责任暴露L1：`11631.594015`；
- 网损责任暴露L1：`416.282021`；
- 边界暴露占比：`96.544768%`。

运行：

```bash
PYTHONPATH=src python -m scale_residual.cli ac-audit --config configs/paper_main.toml
```

无需PYPOWER等额外依赖。
