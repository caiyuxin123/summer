# Legacy cross-period result asset

This directory preserves the recovered historical `rts_conventional_global_results.csv` values.

Important provenance boundary:

- The historical CSV proves that Jan-target and Jun-target experiments were actually executed and saved.
- The exact calendar windows and the exact historical script that generated these values were not recovered with sufficient certainty.
- Therefore these files are **provenance-only legacy assets**. They are not the current v8 paper baseline and are not used by automatic verification.
- The v8 reproducible cross-period baseline is generated by `scale-residual cross-period` and frozen in `reference/expected_cross_period_*.csv`.
- `Proposed-ST` is the historical name corresponding to the later `Full-ST` concept, but numerical values must not be mixed across versions.
