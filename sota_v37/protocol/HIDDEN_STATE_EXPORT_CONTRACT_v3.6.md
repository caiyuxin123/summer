# v3.6 校准隐状态导出契约（冻结版）

1. `calibration_120_state.npz` 只由冻结历史池及其120个物理一致扰动场景生成，不含 February 正式目标窗信息。
2. 状态标签采用 168 h 周模板，共48维：3个 Area 负荷归一化轨迹 + 45个可调度单元归一化出力轨迹。负荷按 Area 基准负荷归一化，机组出力按对应 `pmax` 归一化。
3. 采用单元级而非仅 Area×电源类型级标签，是为了保留网络位置差异；Area×电源类型月度发电量仍作为公共物理投影的硬统计边界。
4. 正式 `target_input_only.npz` 继续只允许 `x_month`、`x_history`、`graph`；不得出现目标期节点—小时负荷、机组出力、潮流、节点 CEF、尺度残差真值或 `y`。
5. 四种比较器第一阶段只能输出候选细粒度状态/伪量测，不直接监督最终3 Area月度责任 `y`。
6. 候选状态进入完全相同的168个“星期类型—小时”代表时段 LP；按 February 2020 的4/5次出现权重恢复696 h月度约束，并统一执行节点CEF、固定Area聚合。
7. 公共LP同时约束：区域月度用电量、Area×电源类型月度发电量、月度分方向跨区交换量、逐时功率平衡、机组容量和线路连续限额。由于冻结 `x_month` 为 float32，月度统计使用 ±0.2 MWh 数值带，仅吸收序列化舍入误差。
8. Reference 只允许在所有比较器实现、超参数和公共投影代码哈希全部冻结后用于一次性正式评价。
