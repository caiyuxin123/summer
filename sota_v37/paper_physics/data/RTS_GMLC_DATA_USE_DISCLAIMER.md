## 1. Canonical RTS-GMLC source

Bundled raw-source files in this directory are derived from **GridMod/RTS-GMLC, release 0.2**.

Canonical repository: https://github.com/GridMod/RTS-GMLC
Pinned release: https://github.com/GridMod/RTS-GMLC/tree/0.2

The RTS-GMLC repository README identifies the dataset as an updated Reliability Test System developed to facilitate production-cost modeling and contains a `DATA USE DISCLAIMER AGREEMENT` for DOE/NREL/ALLIANCE data.
