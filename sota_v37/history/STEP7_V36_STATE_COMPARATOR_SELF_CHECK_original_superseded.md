# SOTA步骤7：论文一致型状态构造比较器 v3.6 实现、锁参与自检报告（2026-09-30）

## 1. 上一步自检结论

v3.5 对 direct-y 管线的“只作诊断、不进论文”处理是正确的，但 v3.6 初始实现再次发现一个需要在正式测试前纠正的问题：若只把候选隐状态压缩为 3 个 Area 负荷轨迹 + 22 个 Area×电源类型发电轨迹，公共投影无法唯一保留同类机组在不同母线上的空间分配，oracle 候选状态经过公共投影后仍产生约 kgCO2/MWh 量级误差。该误差属于比较器接口本身，而不是学习模型误差，因此不能带入正式 SOTA 比较。

本轮已把候选状态升级为单元级 168 h×48 表示：3 个 Area 负荷轨迹 + 45 个 dispatch-unit 出力轨迹。升级后，在校准验证场景 109 上，将真实隐状态直接送入公共投影，最终月度责任 MAE 仅为 `1.81e-05 kgCO2/MWh`，可视为纸面精度下无损。这一 oracle-state gate 通过后，才冻结 v3.6。

## 2. 正式 v3.6 比较器

与论文 3.3 节一致，正式主比较器为：

- PI-GNN adapted：保留图消息传递、物理信息融合与时序状态恢复机制；
- SF* adapted：保留欠定物理/粗观测增强特征与线性状态预测机制；
- PM* adapted：保留增强特征预测缺失量/伪量测，再进入物理估计的机制；
- PM-DSE adapted：保留历史时序分解生成伪量测，再进入物理估计的机制。

四种方法都不直接监督最终 3 Area 月度责任 y。第一阶段统一输出候选细粒度状态，第二阶段进入 byte-identical 的公共物理投影，再执行同一节点 CEF 和固定 Area 聚合。

## 4. 公共物理投影

公共投影在 168 个“星期类型—小时”代表时段上求解稀疏 LP，再按照 February 2020 中每个代表时段出现 4 或 5 次的冻结权重扩展至 696 h。

统一约束包括：

- Area 月度终端用电量；
- Area×电源类型月度发电量；
- 月度分方向跨区交换量；
- 逐时系统功率平衡；
- 单元容量边界；
- DC 连续线路限额。

目标函数为候选负荷轨迹和 45 单元候选出力轨迹的容量归一化 L1 偏差。`x_month` 以 float32 冻结后，各独立聚合统计量存在约 `1e-2 MWh` 的序列化舍入不一致，因此月度统计采用固定 `±0.2 MWh` 数值带；该带只吸收浮点舍入，远小于论文报告精度。所有方法完全共享该投影代码。
